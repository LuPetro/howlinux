# howlinux 1.1.0

howlinux 1.1.0 adds deterministic quality tooling for knowledge authors and
uses a broader evaluation set to make confident search results more
conservative. Runtime search remains local, offline, and non-executing.

## Highlights

- `validate` now detects normalized alias collisions, overly similar aliases,
  duplicate and overly broad keywords, unused concepts, and invalid or
  non-reciprocal related-entry links
- Markdown lint detects unclosed code fences, missing local link targets, and
  links that escape the knowledge root without making network requests
- Human-readable and JSON validation reports include lint coverage counters
  and clearly scoped diagnostics
- Ranking evaluation now covers 82 positive and 15 negative queries
- The confident-result threshold increased from 70 to 90 after the expanded
  dataset exposed false confident answers for unsupported tasks

## Upgrade

Download the `.tar.gz` file and `SHA256SUMS` into the same directory, then run:

```bash
sha256sum --check SHA256SUMS
mkdir -p "$HOME/.local"
tar -xzf howlinux-1.1.0-Linux-x86_64.tar.gz -C "$HOME/.local"
"$HOME/.local/bin/howlinux" validate
```

Existing third-party knowledge directories may now produce additional lint
warnings from `validate`. Valid entries still load for normal searches; lint
findings only cause the validation command to return exit code `1`.
