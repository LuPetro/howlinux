# howlinux 1.2.0

howlinux 1.2.0 adds Arch Linux support for source builds and installation,
alongside a curated `pacman` reference. It is a backward-compatible feature
release: existing CLI commands, JSON output, and knowledge schemas remain
unchanged.

## Highlights

- Source builds work with Arch's shared-only `yaml-cpp` package.
- Arch Linux CI exercises Debug and Release, installed execution, relocated
  archives, explicit shared linkage, and the installation script.
- Package searches such as `howlinux "install arch linux package"` find the
  new `pacman` reference, including full-system-upgrade guidance.

## Install on Arch Linux

```bash
sudo pacman -Syu --needed base-devel cmake yaml-cpp git
git clone https://github.com/LuPetro/howlinux.git
cd howlinux
git checkout v1.2.0
./scripts/install.sh
"$HOME/.local/bin/howlinux" validate
```

The dependency command also upgrades the system; review Arch news and the
proposed transaction before confirming. Keep `yaml-cpp` installed for source
builds that use its shared library.

## Build compatibility

`HOWLINUX_STATIC_YAML_CPP` now defaults to `AUTO`, preferring static linkage
when available and otherwise using the installed package target. Existing
explicit `ON` and `OFF` settings retain their meanings. For an old build cache
on Arch, configure with `-DHOWLINUX_STATIC_YAML_CPP=AUTO`. The installer sets
this automatically unless its corresponding environment variable is supplied.

Official release archives still require static `yaml-cpp` at build time and
do not depend on its shared-library ABI. Locally packaged shared builds need
a compatible `yaml-cpp` runtime package on the target system.

## Upgrade from an archive

Once the release is published, download its `.tar.gz` and `SHA256SUMS` files:

```bash
sha256sum --check SHA256SUMS
mkdir -p "$HOME/.local"
tar -xzf howlinux-1.2.0-Linux-x86_64.tar.gz -C "$HOME/.local"
"$HOME/.local/bin/howlinux" validate
```
