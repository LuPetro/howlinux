# howlinux 1.0.1

howlinux 1.0.1 is a backward-compatible content and quality update. The
runtime contract remains unchanged: answers are curated, deterministic,
offline, and never executed.

## Highlights

- 38 reviewed knowledge entries, up from 5 in v1.0.0
- New coverage for everyday file, text, storage, process, networking, systemd,
  logging, package-management, and archive tasks
- Safety guidance for destructive operations, remote access, downloads,
  package changes, and untrusted archives
- Expanded metadata, concepts, realistic aliases, and related-entry links
- A versioned evaluation set that measures top-1 accuracy, recall at five, and
  false confident matches during the release audit

## Upgrade

Download the `.tar.gz` file and `SHA256SUMS` into the same directory, then run:

```bash
sha256sum --check SHA256SUMS
mkdir -p "$HOME/.local"
tar -xzf howlinux-1.0.1-Linux-x86_64.tar.gz -C "$HOME/.local"
"$HOME/.local/bin/howlinux" validate
```

Extracting into the same prefix replaces the executable and installs the
expanded knowledge directory. Locally added entries should be backed up first
if they were placed inside that installed directory. A separately selected
directory via `HOWLINUX_KNOWLEDGE` or `--knowledge` is not modified.
