# howlinux 1.0.0

The first stable release of howlinux provides fast, deterministic, offline
search over a human-reviewed Linux knowledge base.

Highlights:

- Curated YAML and Markdown answers; no generated text or command execution
- Explainable lexical ranking with concepts and bounded typo matching
- Conservative handling of ambiguous and unrelated queries
- Human-readable output plus stable, ANSI-free JSON
- Built-in list, show, and validation commands
- Shell completions, man page, installer, and portable Linux archive

## Install the archive

Download the `.tar.gz` file and `SHA256SUMS` into the same directory, then run:

```bash
sha256sum --check SHA256SUMS
mkdir -p "$HOME/.local"
tar -xzf howlinux-1.0.0-Linux-x86_64.tar.gz -C "$HOME/.local"
"$HOME/.local/bin/howlinux" validate
```

The release archive targets x86-64 Linux and is built on Ubuntu 22.04 for
compatibility with newer supported Ubuntu releases. Building from source is
documented in the README.
