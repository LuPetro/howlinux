# Security policy

howlinux is designed to run offline. It does not execute commands from user
queries or from Knowledge answers.

## Supported versions

| Version | Supported |
| --- | --- |
| 1.2.x | Yes |
| 1.1.x | Yes |
| 1.0.x | Yes |
| Earlier versions | No |

## Report a vulnerability

Please use **Security -> Report a vulnerability** in this GitHub repository to
open a private security advisory. Do not open a public issue for an unpatched
vulnerability.

Include the affected version, platform, reproduction steps, expected and
actual behavior, and potential impact. Reports should not contain unrelated
personal data or production credentials. You will receive an acknowledgement
through the private advisory; remediation and disclosure timing will be
coordinated there.

If private vulnerability reporting is not enabled, open a public issue that
asks the maintainer to enable it, without including exploit details.
